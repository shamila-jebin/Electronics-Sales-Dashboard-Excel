# 📊 Electronics Sales Dashboard – Excel

## 📌 Project Overview
The Electronics Sales Dashboard is an interactive dashboard created using Microsoft Excel to analyze electronics sales performance across different cities, product categories, and sales representatives.

It provides a visual overview of sales trends and helps users understand product-wise performance, city-wise sales, and monthly sales patterns.

## 📈 Dashboard Features
- **Sales by City** – Compare sales across different cities.
- **Sales by Category** – Analyze sales for Phones, Headphones, and Laptops.
- **Product-wise Sales** – Compare sales across products.
- **Sales by Sales Representative** – Evaluate individual sales performance.
- **Monthly Sales Analysis** – Explore sales across different months.
- **Interactive Month Filter** – Filter dashboard data by month.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Slicers
- Data Analysis
- Data Visualization

## 🎯 Project Objective
The objective of this project is to transform sales data into an interactive dashboard that helps analyze sales performance, identify top-performing cities and products, and compare sales representatives.

## 🔍 Key Insights
The dashboard allows users to:
- Compare sales performance across cities.
- Identify high-performing product categories.
- Analyze product-wise sales.
- Compare sales representatives.
- Explore monthly sales patterns using the month filter.
